# ADR-0011: 식자재몰 배달 가능 판정은 가게 시군구 한 칸과 전역 배송 지역 표 `market_site_delivery_area` 로 한다

- 상태: 채택
- 영역: backend
- 결정 로그: [DECISIONS #70](../DECISIONS.md)
- 관련 이슈: S15P31A308-230

## 맥락

- 재료별 식자재몰 최저가(`GET /ingredients/{id}/offers`, ADR-0010)는 7개 몰이 전부 나온다. 식봄은 서울 중구 배송 상품만 수집했고, 식자재왕몰은 점포 10곳이 각자 주변에 배달하며 점포마다 가격이 다르다. 사장님 가게에 오지 않는 몰의 최저가는 발주에 쓸 수 없다.
- `store` 에는 주소 칸이 없다(네이버 플레이스 ID 만 있다). 가게 위치를 어디선가 받아야 한다.
- 몰의 배송 지역은 데이터셋에서 아는 범위(식봄 = 서울 중구, 식자재왕몰 = 점포명, 마켓컬리 = 전국)뿐이고, 농협몰 · 오아시스마켓 · 그리팅몰 · 아워홈몰은 모른다. 모르는 것을 배달 불가로 숨기면 사장님이 쓸 수 있는 몰이 사라진다.

## 결정

- 가게 위치는 `store.sigungu` 한 칸(V6). `"<시도> <시군구>"` 한글 글자 그대로(`서울 중구` · `경기 성남시`). `PATCH /stores/me { sigungu }` 로 받고 `GET /stores/me` 가 돌려준다. 전체 주소 · 좌표 · 지오코딩은 두지 않는다.
- 배송 지역은 **가게 스코프 없는 전역 참조 표** `market_site_delivery_area`(site · store_region · sigungu · dawn_delivery). ADR-0002 의 두 번째 예외(첫째는 ADR-0010). 한 줄 = "이 사이트(의 이 점포)가 이 시군구에 배달한다". `store_region` NULL = 사이트 전체, `sigungu` NULL = 전국, `dawn_delivery` NULL = 모름. JPA 엔티티 없이 JDBC 로 전부 읽는다(수십 줄).
- 판정(`DeliveryCoverage.check(site, storeRegion)`): 가게 시군구가 없거나 사이트에 줄이 없으면 **UNKNOWN**('확인 필요', 응답 `deliveryUnknown`), 맞는 줄이 있으면 **AVAILABLE**, 줄은 있는데 안 맞으면 **BLOCKED**(응답에서 빼고 `notDelivering` 에 이름만). UNKNOWN 은 숨기지 않는다 — 모르는 것과 안 되는 것을 구분한다.
- 시드는 데이터셋에서 확인한 범위만 V6 에 넣는다. 식자재왕몰은 점포가 있는 시군구 하나씩(실제 배송권은 더 넓을 수 있다). 배송 지역을 더 알게 되면 **새 마이그레이션으로 줄을 보탠다**. 운영 API 로 고치지 않는다.

## 버린 대안

| 대안 | 왜 안 골랐나 |
|---|---|
| 전체 주소 + 좌표 저장, 거리로 판정 | 지오코딩 외부 API 가 필요하고 몰은 거리가 아니라 행정구역으로 배송권을 정한다 |
| 네이버 플레이스 ID 에서 주소를 다시 수집 | 온보딩을 안 거친 가게는 ID 가 없고, 수집 코드가 한 칸 때문에 늘어난다. 시군구 한 칸이면 사장님이 바로 적는다 |
| 배송 지역을 `market_product` 줄마다 붙임 | 48만 줄에 같은 값을 반복 저장하고, 스냅샷 교체마다 다시 붙여야 한다 |
| 모르는 몰을 배달 불가로 숨김 | 농협몰 · 오아시스 등 전국 택배 몰이 사라진다. 모르는 것은 '확인 필요'로 보여 주는 게 맞다 |
| 사장님이 몰별 배달 가능 여부를 직접 켜고 끔 | 가게마다 설정이 늘고, 몰의 배송권이 바뀌면 전부 다시 켜야 한다. 나중에 '확인 필요' 몰에 한해 덧붙일 수 있다 |

## 결과

- **좋아지는 것**: 서울 중구 밖 가게에 식봄 가격이 나오지 않고, 식자재왕몰은 배달 오는 점포 가격만 남는다. 모르는 몰은 '확인 필요'로 남아 사장님이 직접 확인할 수 있다. 배송 지역 추가는 SQL 몇 줄이다.
- **감수하는 것**: 시군구 글자가 정확히 같아야 한다(`서울특별시 중구` 는 못 맞춘다 — 입력 화면이 목록에서 고르게 해야 한다). 식자재왕몰 배송권을 점포 소재 시군구 하나로 좁게 잡아 실제보다 적게 보일 수 있다. 가게 스코프 예외 표가 둘이 됐다.
- **다시 볼 시점**: 시군구 표기가 어긋나는 가게가 생기면 행정구역 코드 표. 식자재왕몰 · 식봄 배송권이 확인되면 시드 보강. 사장님이 '확인 필요' 몰을 직접 켜고 끄길 원하면 가게별 설정 표.
