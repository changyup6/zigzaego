# POS · 배달앱 export 형식 조사

> 소형 식당이 많이 쓰는 포스 · 배달앱 사장님 사이트에서 **메뉴별 · 일별 · 채널별 판매를 엑셀로 뽑을 수 있는지** 조사한 결과.
> 업로드 파서의 벤더 어댑터(S15P31A308-38)를 어디부터 만들지 정하는 근거다. 뽑은 파일이 어떤 표준 행이 되는지는 [판매 데이터 사전](판매_데이터_사전.md).

**위글리 포스 벤더: 미확인.** 사장님 미팅(S15P31A308-13)에서 확인한다. 그 전까지는 아래 표로 "어느 벤더면 무엇이 되는가"만 정리해 둔다.

표기: **✅** 공식 도움말 · 매뉴얼에서 확인 / **△** 검색 요약 · 오래된 자료 · 비공식 글로만 확인 / **?** 근거를 못 찾음(없다는 뜻이 아니다)

## 1. 결론 먼저

| 벤더 | 메뉴 × 일 엑셀 | 채널 구분 | 어댑터 난이도 |
|---|---|---|---|
| 토스플레이스 | ✅ 주문 건 단위 시트 → 일 · 메뉴로 합치면 됨 | ✅ "주문채널" 열. 배달 3사 연결 시 POS에 합산 | 낮음 |
| 페이히어 | ✅ "일자별 상품 매출 내역" 시트 | ✅ 결제내역 채널 필터(배달). 엑셀 열 이름은 ? | 낮음 |

- **포스에서 배달까지 한 번에 받는 게 기본 경로다.** 토스플레이스 · 페이히어 · OKPOS는 배달앱 주문을 포스로 모아 채널을 구분해 준다 → 데이터 사전 4절의 **A 경우**
- **배달앱 사이트만으로는 메뉴별 일 판매를 얻기 어렵다.** 정산 · 매출내역서(금액 중심)는 받아도 메뉴 열은 확인되지 않았다. 배달 1년치가 배민 사장님 사이트에만 있다면 위험 신호다
- 조회 기간 한도가 6개월인 곳이 많다. **1년치는 6개월씩 두 번 받아야 할 수 있다**

## 3. 미팅에서 확인할 것 (S15P31A308-13)

조사로 답이 안 나오는 것만 남겼다. 질문지(`docs/meetings/사장님_미팅_질문지.md` 1절)와 겹치는 건 그 답으로 채운다.

1. 포스 회사 이름 → 위 표의 어느 줄인지
2. 포스 관리자 화면에서 **"일자별 × 상품별"** 보고서가 엑셀로 내려오는지 — 화면 캡처 + 파일 1개
3. 배달앱 주문이 포스에 들어오는지, **언제부터** 연결했는지 (토스플레이스는 연결 전 매출이 합산되지 않는다)
4. 배달 1년치가 포스에 없다면: 요기요 주문내역 엑셀에 메뉴 열이 있는지, 배민은 어디서 뽑는지
5. 홀 / 포장 / 배달이 엑셀 어느 열로 구분되는지

## 4. 어댑터 순서 제안

1. **샘플 포맷 어댑터** — 지금 있는 `ai/data/sample/pos_sales.csv` 형식. 테스트 기준 (S15P31A308-38 완료 조건)
2. **위글리 실제 벤더 어댑터** — 미팅 뒤, 받은 파일로
3. 그 다음 후보는 공식 문서로 형식이 확인된 **토스플레이스 · 페이히어**. 실물 파일 없이도 열 이름까지 알 수 있다
