# 결정 로그

> **이 파일이 단일 진실 원천이다. 다른 문서와 여기가 다르면 여기가 맞다.**

## 이 파일을 쓰는 이유

기획은 계속 바뀐다. 바뀐 결정이 회의 · 메신저 · Jira 댓글에만 남고 문서에는 안 들어가면, 구현하는 사람이 옛 문서를 보고 옛 설계대로 만든다. 그걸 막는 유일한 방법은 **결정이 나면 그 자리에서 여기에 한 줄 남기는 것**이다.

## 운영 규칙

1. **결정을 지우지 않는다.** 뒤집힐 때는 새 번호로 추가하고, 기존 항목 상태를 `변경됨 → #N`으로 바꾼다
2. **결정이 바뀌면 같은 MR에서 관련 문서도 고친다.** 문서 수정 없는 결정 변경 MR은 머지하지 않는다
3. **각 결정은 반영된 문서를 링크한다.** 링크가 없으면 아직 문서에 안 들어간 것이다
4. **최종 수정일을 손으로 적지 않는다.** `git log -1 --format=%cd -- docs/DECISIONS.md`
