## FreshRetailNet-50K (매장×상품 일별 판매 — 메뉴 단위 대리)

- 시험 기간: 2024-05-29 ~ 2024-06-25
- 평가 계열 1,000개 — 매장×상품 계열 50,000개 중 시드 42 로 뽑았다. 자료 기간 2024-03-28 ~ 2024-06-25(90일), 마지막 28일이 시험 기간. 원본이 이미 일 단위 판매량(sale_amount)이라 그대로 썼다.
- 원본에는 휴무일 행이 없다(모든 계열이 90일 다 있음). 판매 0 인 날도 기록이므로 채점에 들어간다.
- 시험 시작 전 기록은 62일뿐이라 **12주(84일) 와 전체는 같은 입력**이다.
- 0 비율 = 시험 시작 전 기록(62일) 중 판매 0 인 날의 비율. 구간마다 따로 채점·판정했다. 구간 계열 수: 0~10% 869개, 10~30% 103개, 30%+ 28개.
- 건너뛴 계열 전체(0 비율 구간을 정할 수 없는 계열 포함): 고정 창 방식 1주 · 단일 계열(채널 칸 없음) 0개, 고정 창 방식 2주 · 단일 계열(채널 칸 없음) 0개, 고정 창 방식 4주 · 단일 계열(채널 칸 없음) 0개, 쌓이는 방식 1주 · 단일 계열(채널 칸 없음) 0개, 쌓이는 방식 2주 · 단일 계열(채널 칸 없음) 0개, 쌓이는 방식 4주 · 단일 계열(채널 칸 없음) 0개, 쌓이는 방식 12주 · 단일 계열(채널 칸 없음) 0개, 쌓이는 방식 전체 · 단일 계열(채널 칸 없음) 0개.
- 실행 시간: 전체 1114.9초, 그중 TimesFM 예측 992.7초(체크포인트 불러오기 1.6초 별도), CPU.
