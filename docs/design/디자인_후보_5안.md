# 위글리 발주 — 대시보드 디자인 방향 후보 5안

작성: 2026-10-06. 현재 프로토타입(흰 종이 + 괘선 + 굵은 숫자, 빨간 레일)이 "심심하고 한눈에 안 들어온다"는 피드백에 대한 리서치 결과.

**공통 진단**: 현재 문법은 Mercury/Stripe류 editorial 계열인데, 그 문법은 *숫자 하나를 크게, 색은 상태에만* 써야 산다. 지금은 빨간 레일이 가장 큰 색 덩어리라 정작 "오늘 뭐 해야 하나"가 색을 못 받는다. 아래 5안은 모두 **① 히어로 1개 + ② 상태색 3개(주문필요/임박/양호) + ③ 공급처별 묶음**을 공통 골격으로 깔고, 룩만 다르게 간다.

## 1. 벤토 작전판 · Bento Ops Board

**레퍼런스**
- Dribbble "Bento grid & dashboard for revops startup" (Robin Holesinsky) — https://dribbble.com/shots/25765472-Bento-grid-dashboard-for-revops-startup (검색으로 존재 확인, 본문 미열람)
- Ramp 디자인 시스템: 웜 블랙 `#1C1B17`, 라임은 CTA에만, 금액은 56px+ tabular — https://oh-my-design.kr/design-systems/ramp
- Stripe 홈: 숫자 5개 + 스파크라인 + "이전 기간" 소문자 비교 — https://www.925studios.co/blog/stripe-dashboard-design-breakdown

**팔레트**: 캔버스 `#F4F2EC` / 타일 `#FFFFFF` / 잉크 `#1C1B17` / 브랜드 레드 `#CF2229`(행동에만) / 앰버 `#E08A1E`(임박·보류) / 그린 `#1A7F4B`(양호)

**타이포**: Bricolage Grotesque(숫자·헤드라인, opsz 축으로 큰 숫자가 좁게 짜임) + IBM Plex Sans KR(본문, 500/600)

**레이아웃**: 12컬럼 벤토. 좌상단 2×2 히어로 타일 = "오늘 승인 대기 **7**" 120px 숫자 + "마감 22:00까지 1h 40m" + 링 프로그레스(승인/전체). 우측 1×2 타일 = 7일 캘린더 세로 스트립(요일·발주 건수 점). 하단 가로 긴 타일 = 오늘 발주 리스트(공급처별 섹션, 행 56px). 입고 예정·양호 재고는 소형 1×1 타일로 격하. 데스크톱은 선택 시 리스트 타일 오른쪽이 디테일 타일로 교체, 모바일은 타일 세로 스택.
"한눈에": 타일 크기 = 중요도. 숫자 하나만 크고 나머지는 전부 14px.

**시그니처**: (a) 히어로 KPI + 링, (b) 타일 헤더 좌측 4px 상태색 바, (c) 행마다 "남은 일수" 미니 스파크라인(재고 추세 7점)

**핏/리스크**: 아침 데스크톱에서 가장 강함. 9pm 폰에선 타일 경계가 사라져 긴 리스트가 되는데, 히어로 타일만 sticky로 두면 해결. 레드는 CTA·"주문필요" 외 금지해야 벤토가 산다 — 레일 레드를 버릴 각오 필요.

## 2. 네오브루탈 주방 칠판 · Neo-brutal Kitchen Board

**레퍼런스**
- Neo-Brutalism Dashboard Template (Next.js) — https://github.com/homayounmmdy/neo-brutalism-dashboard-template , 데모 https://neo-brutalism-dashboard-template.vercel.app/
- Figma "17 Screens NeoBrutalism Admin Dashboard UI Kit" — https://www.figma.com/community/file/1601916523900495011/17-screens-neobrutalism-admin-dashboard-ui-kit
- Toast KDS Grid 레이아웃(티켓이 그리드 슬롯에 정렬, 주황 체크=착수) — https://support.toasttab.com/en/article/Grid-KDS-Overview

**팔레트**: 크림 `#FFF6E0` / 블랙 `#111111` / 토마토 `#CF2229` / 파스타 옐로 `#FFD23F` / 바질 `#2F9E5B` / 스카이 `#7DB7FF`(입고 예정)

**타이포**: Archivo Black + Archivo(현재 자산 유지, 숫자는 Archivo Black 72px) + 한글 헤드라인 Black Han Sans(섹션 타이틀 1줄만) + 본문 Gothic A1 500

**레이아웃**: 발주 리스트를 **KDS 티켓** 메타포로 — 재료 1개 = 카드 1장, 2px 검정 테두리 + `4px 4px 0 #111` 오프셋 섀도, 카드 좌측에 24px 상태 탭(토마토/옐로/바질). 캘린더는 상단 7개 청키 칩(오늘 = 검정 채움 + 흰 글자). 디테일은 데스크톱에서 오른쪽 "포스트잇" 카드(옐로 배경, 회전 -1deg), 모바일은 풀스크린 시트. 히어로 = 좌상단 스탬프 블록 "승인 대기 7 / 마감 22:00".
"한눈에": 토마토 탭 카드만 세면 끝. 양호 재고는 테두리만 있는 빈 카드로 접힘.

**시그니처**: (a) 하드 오프셋 섀도 + 2px 보더, (b) 회전 스탬프 배지("승인됨"/"보류"), (c) 56px 청키 스테퍼(−/수량/+)가 카드 안에 내장

**핏/리스크**: 터치 타깃·대비 최상, 어두운 주방에서 크림+검정은 잘 읽힘. 리스크는 "장난감" 느낌 — 색을 3개로 묶고 블랙 보더를 1.5px로 낮추면 프랜차이즈 톤 유지 가능. 재료 40개 이상이면 카드가 너무 길어지므로 공급처별 접기 필수.

## 3. 다크 라인쿡 콘솔 · Dark Line-Cook Console

**레퍼런스**
- Linear UI 리디자인: LCH 기반 테마(베이스·액센트·대비 3변수), 서피스 엘리베이션, 액센트 절제 — https://linear.app/now/how-we-redesigned-the-linear-ui
- Vercel Geist: Geist Mono를 tabular 숫자·식별자에 — https://www.shadcn.io/design/vercel
- KDS UX 케이스 스터디(빨강 남용으로 상태 구분 실패, 작은 폰트 문제) — https://medium.com/@osamahaashir/cooking-up-success-revamping-kitchen-display-system-kds-ux-case-study-6a6c92784fb9

**팔레트**: 베이스 `#0F1011` / 패널 `#1A1B1E` / 텍스트 `#F7F8F8` / 레드 `#F4515A`(`#CF2229`는 검정 위에서 대비 3.3:1로 탈락, LCH로 밝힘) / 앰버 `#FFB224` / 그린 `#3DD68C`

**타이포**: Geist Mono(수량·남은 일수·시각, `font-variant-numeric: tabular-nums`) + Geist(라틴 UI) + Noto Sans KR 500/700(다크에서 400은 가늘어 보임)

**레이아웃**: 좌측 레일을 56px 아이콘 레일로 축소(레드 레일 폐기). 상단 띠 = 7일 세그먼트 컨트롤(각 칸 아래 발주 건수 점). 본문 = 고밀도 테이블(행 48px), **행 좌측 3px 상태 레일** + 상태 도트 글로우. 우측 320px 인스펙터(Linear 스타일) = 선택 재료의 타임라인 바가 패널보다 한 단계 밝은 서피스 위에서 발광. 히어로 = 상단 띠 우측 "마감까지 01:40" 카운트다운 + "미승인 7" 칩.
"한눈에": 색은 상태 레일·도트에만 → 어두운 배경에서 레드 점 7개가 바로 튄다.

**시그니처**: (a) 3px 행 상태 레일, (b) 모노 tabular 숫자 열 정렬, (c) 카운트다운 + 글로우 도트

**핏/리스크**: 9pm 폰·어두운 주방에서 압도적. 아침 밝은 홀에서는 눈부심 → `prefers-color-scheme`로 라이트 자동 전환(LCH로 생성하면 토큰 1벌). 리스크는 "개발자 툴" 인상 — 파스타 사장님 페르소나와 거리감. 입고/양호 섹션은 접힘 기본.

## 4. 토스식 카드 피드 · Toss-style Card Feed

**레퍼런스**
- Toss 디자인 시스템: 블루 `#3182F6`, 20px 라운드, 카드 1장=행동 1개 — https://oh-my-design.kr/design-systems/toss
- 채널톡 Bezier(국내 B2B SaaS 중 가장 정돈된 오픈 시스템) — https://channel.io/ko/blog/update-design
- 마켓봄(자주 주문하는 상품 상단 고정, 사장님 발주 앱의 국내 표준) — https://apps.apple.com/us/app/id1099676457
- 캐시노트는 디자인 공개 자료가 없어 Mobbin "Inventory management dashboard" 컬렉션으로 대체 — https://mobbin.com/explore/web/screens/inventory-management-dashboard

**팔레트**: 배경 `#F2F4F6` / 카드 `#FFFFFF` / 잉크 `#191F28` / 그레이 `#8B95A1` / 레드 `#CF2229`(승인 CTA·주문필요) / 블루 `#3182F6`(입고 예정)

**타이포**: Noto Sans KR 500/700 단일 + 숫자만 Inter Tight(tnum). Pretendard를 원하면 jsDelivr CDN으로 교체 가능(구글폰트 아님).

**레이아웃**: 모바일 퍼스트 피드. 최상단 요약 카드(히어로) = 한 문장 "오늘 **3건** 승인하면 끝나요" + 승인 전체 버튼. 그 아래 7일 캘린더 가로 칩 스크롤. 리스트는 **공급처별 카드 그룹**(헤더에 공급처 칩 + 마감 시각), 행 64px, 우측에 수량 28px 700. 탭 → 바텀시트(타임라인·스테퍼·승인/보류). 데스크톱은 2컬럼 + 우측 드로어. 입고 예정은 블루 띠 카드, 양호 재고는 "더보기" 접힘.
"한눈에": 문장 1개 + 레드 CTA 1개. 나머지는 회색.

**시그니처**: (a) 20px 라운드 카드 + 우측 큰 숫자, (b) 공급처 그룹 헤더 + 마감 뱃지, (c) sticky 하단 "전체 승인" 바

**핏/리스크**: 국내 사장님에게 학습 비용 0 — 배민사장님·토스 사장님과 같은 손맛. 9pm 폰에서 최적. 리스크는 "흔한 국내 핀테크" 룩으로 브랜드가 사라지는 것(레드 CTA·아이콘으로 버텨야 함), 데스크톱에서 늘어난 폰 앱처럼 보일 수 있음.

## 5. 웜 세라믹 · Warm Ceramic (트라토리아 톤)

**레퍼런스**
- Mercury: "순백 금지" 오프화이트, 480 커스텀 웨이트, 쿨 섀도 — 여기선 웜으로 뒤집음 — https://oh-my-design.kr/design-systems/mercury
- Dribbble neumorphism-dashboard 태그 — https://dribbble.com/tags/neumorphism-dashboard
- Behance "Kitchen Display Systems (KDS)" UX/UI — https://www.behance.net/gallery/187918001/Kitchen-Display-Systems-(KDS)-UX-Design-UI-Design (상태 색·타이머 참고)

**팔레트**: 베이스 `#F1EAE0` / 카드 `#FBF8F2` / 에스프레소 `#2B211C` / 테라코타 `#C8553D`(브랜드 레드를 따뜻하게 시프트) / 올리브 `#6B7F4A` / 사프란 `#E9A23B`

**타이포**: Fraunces(세리프 디스플레이 숫자, SOFT 축 활용) + Gowun Batang(한글 섹션 제목) + Noto Sans KR 본문

**레이아웃**: 상단 "주간 리본" = 7일이 부드러운 필 탭, 오늘은 테라코타 채움. 히어로 = 리본 아래 Fraunces 96px "7" + "오늘 발주". 리스트는 공급처별 **인셋 소프트 카드**(1px 보더 필수 — 순수 뉴모피즘은 대비 탈락), 각 행 우측에 **남은 일수 링**(테라코타→사프란→올리브). 디테일은 데스크톱에서 떠 있는(raised) 카드, 모바일은 시트. 입고 예정은 올리브 띠, 양호 재고는 접힘.
"한눈에": 링 색만 훑으면 됨 — 테라코타 링 = 오늘 주문.

**시그니처**: (a) 재료별 남은 일수 링, (b) 인셋 스테퍼(눌리는 느낌), (c) 세리프 숫자 히어로

**핏/리스크**: 파스타·호스피탈리티 톤이 가장 맞고 브랜드와도 어울림. 리스크는 대비 — 저가 폰 패널·어두운 주방에서 소프트 섀도가 뭉개짐. 보더 1px + 에스프레소 텍스트 700으로 보정하고, 다크 모드는 만들지 않는 편이 낫다(뉴모피즘 다크는 거의 실패).

## 추천

- **가장 "한눈에" 효과 큰 것**: 3번(다크 콘솔)과 1번(벤토). 3번은 9pm 폰 사용성이 압도적, 1번은 아침 데스크톱.
- **브랜드·사장님 페르소나 균형**: 2번(네오브루탈)을 색 3개로 절제한 버전이 가장 "위글리답고" 심심하지 않다.
- **현재 코드 최소 변경**: 현 레이아웃 유지 + 1번의 히어로 타일 + 3번의 3px 행 상태 레일만 이식. 레드 레일은 어느 안을 고르든 **폐기 또는 아이콘 레일로 축소** — 색 예산을 상태에 돌려야 한다.
