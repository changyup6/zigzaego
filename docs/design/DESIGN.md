# Design System: 지그재고

> 정본은 [`prototype/app_all.html`](prototype/app_all.html) ([DECISIONS #60](../DECISIONS.md)). 이 문서와 시안이 다르면 시안이 맞다.
> 홈 · 발주 화면은 [`prototype/home_v3.html`](prototype/home_v3.html) · [`prototype/order_v5.html`](prototype/order_v5.html)이 정본이다 ([DECISIONS #72](../DECISIONS.md)).
> 화면을 만들 때는 시안의 해당 화면 CSS를 그대로 옮긴다. 새 화면도 시안에 있는 부품(카드 · 행 · 버튼 · 선택 칸 · 시트)만 조합한다.

## Overview

사장님 연령대가 높다는 전제로 **글자와 숫자가 크고, 한 화면에 할 일이 적은** 운영 화면이다.
미색 바닥(`bg`) 위에 오른쪽 위 붉은 빛(`glow`)이 번지고, 그 위에 반투명 흰 유리 카드가 놓인다. 강조는 빨강 하나, 무게는 어두운 카드(`dark`) 하나로 준다.

- 화면 머리는 52px 얇은 제목 한 줄(`hero`). 강조 숫자만 빨강
- 숫자는 Lexend 얇은 굵기. 단위는 숫자 옆 작은 회색 글자(`<u>`)
- 설명 문장 · 안내 문구 · 리드 문장을 넣지 않는다. 숫자 · 이름 · 상태로 보여준다. 예외는 레시피 탭의 "레시피를 확인해주세요!" 한 줄
- 이름 옆에 "확인 필요" · "추정" · "AI" 같은 글자 딱지를 붙이지 않는다. 확인할 것은 묶음 순서와 그 칸 표시로 보인다
- 쉬운 말만 쓴다. 리드타임 → 배송 기간, 발주점 → 주문 기준

| `step-done` | `#4E8466` | 온보딩 진행 막대의 채운 칸 (빈 칸은 `rule`) |

### Named Rules

- 빨강은 "지금 해야 할 것"에만. 주 버튼, 소진 임박, 입고 예정
- 선택 상태는 언제나 `dark` 바탕 흰 글자 (탭 · 칩 · 요일 · 주문처 선택 · 연월 선택)
- 그림자는 토스트 · 폰 하단 탭 막대 · 액션 바에만
- 글자는 바탕과 대비 4.5:1 이상. 누르는 칸은 높이 44px 이상 (DECISIONS #103)

숫자 표시는 천 단위 쉼표를 쓰고 기존 소수 첫째 자리 반올림을 유지한다(예: `1,234.5`). 개수 재고는 기존 내림 정수를 유지한다. 입력 값 · API 수량 · 계산은 원시 숫자다.

| 숫자 | 20px(행) · 28px(입고 예정) · 32px(카드 머리 개수) · 46px(합계) · 300~400 |

## Layout

- 최대 폭 1360px, 좌우 28px (폰 16px), 카드 간격 16px
- 데스크톱 상단: 로고 · 가운데 알약 모양 탭 막대 · 날짜. 폰: 탭 막대가 화면 아래에 떠 있다
- 발주 화면은 왼쪽 추천 품목 목록(품목을 누르면 그 자리에서 펼침) + 오른쪽 380px(매출 예측 카드 · 발주 목록) 2열. 폰은 매출 예측 카드가 위, 발주 목록은 아래 액션 바(개수 · 합계 · 발주하기)
- 화면 아래 고정 액션 바는 발주 화면 · 온보딩에만 (폰은 탭 막대 위). 합계가 있으면 `dark` 알약 안에 합계 + 버튼, 버튼 하나면 알약 없이 버튼만 띄운다
- 온보딩 가게 찾기의 "다음"은 가게를 고르거나 링크를 넣었을 때만 나타난다

## Shapes

카드 30px, 행 18px, 입력 · 타일 14px, 버튼 · 칩 · 태그는 알약(999px), 시트는 위만 30px. 홈 매출 예측 카드 24px(`r-widget`), 분석 상자 22px(`r-bubble`), 요일 막대 6px(`r-bar`).

## Components

### Buttons
`primary`(빨강) · `ghost`(soft) · `glass`(어두운 카드 위) · `quiet`(바탕 없음). 높이 46px, 작은 버튼 44px. 누르면 0.97로 줄어든다.

### Card
기본은 유리 카드. 오늘 입고 예정처럼 무게를 줄 카드만 `dark`. 카드 머리는 제목(18px) + 오른쪽 개수(32px 숫자) 또는 화살표 원.

### 홈 (DECISIONS #61 · #72)
인사말 오른쪽에 작은 매출 예측 카드(폰은 인사말 아래 띠), 그 아래 카드 전체가 눌리는 큰 버튼 두 개. 제목 30px, 품목 이름 · 수량 22px, 아래 68px 알약 버튼. 첫째는 어두운 그라디언트 + 빨간 버튼(오늘 발주 추천 품목 → 발주): 품목마다 추천 주문처 · 금액, 아래 "기존 거래처에서만 살 때보다 −N원" 한 줄, 버튼에 합계. 둘째는 유리 카드 + 어두운 버튼(오늘 입고 예정 품목 → 발주 이력).
발주 카드를 누르면 화면 전환(View Transition, 0.8s)으로 카드 · 제목 · 품목명 · 수량 · 매출 카드가 발주 탭의 같은 자리로 이어지고, 추천 품목이 담긴 채 열린다.

### 매출 예측 카드 · 모달 (DECISIONS #72 · #97 · #107)
접힌 카드는 기존 `red` 바탕과 흰 글자·막대를 유지한다(DECISIONS #101). "이번 주 매출 예측", 큰 % 숫자, 이유 한 줄, 요일 막대 7개를 보인다. 펼친 모달은 `forecast-surface` 중성 미색 바탕, `forecast-ink` 검정 본문, `forecast-muted` 진회색 보조 글자이며 큰 수치·최대 막대·기여도 막대에만 `forecast-accent` 빨강을 쓴다. 일반 요일 막대는 `forecast-bar` 회색이고 분석 상자는 `forecast-panel` 흰색이다. `forecast-*`는 기존 중성·빨강 토큰의 모달 전용 별칭이다. 누르면 카드가 그 자리에서 커져 모달이 된다(clip-path 스프링, 숫자 · 막대가 제자리에서 커짐). 펼칠 때 560ms 동안 고정 제목 줄의 배경·글자까지 포함해 카드의 빨강·흰 글자·흰 막대가 모달의 중성 배경·강조색·회색 막대로 서서히 바뀌며, 닫을 때는 70ms 대기 후 320ms 동안 역방향으로 돌아온다. 여는 도중 닫으면 현재 위치와 색에서 이어지고, 동작 줄이기 설정에서는 전환과 대기를 생략한다. 모달 왼쪽 숫자 · 막대 · 이유별 기여 막대, 오른쪽 분석 문장(타이핑). 폰은 한 칸, 제목 줄 · 닫기는 스크롤해도 위에 고정, 뒤 페이지는 스크롤되지 않는다. 오른쪽 아래 작은 글씨 "지그재고 AI 매출 예측은 틀릴 수 있습니다"는 설명 문구 금지의 예외다.

실제 데이터는 `GET /sales-forecast/this-week`를 사용한다. 로딩만 skeleton이며, 예측이 없거나 조회에 실패하면 상태와 다시 불러오기를 표시한다. `analysis`가 없으면 숫자와 요인은 유지하고 빈 분석 상자는 숨긴다. 날짜 수가 7개보다 적어도 응답에 있는 날짜만 그리며 요일 값은 평소 100 기준 지수다. #101의 카드/모달 색상 전환을 유지한다.

### 행 (irow)
반투명 흰 행 18px 모서리. 선택된 행은 흰 바탕 + 1.5px 잉크 테두리. 보류 행은 흐리게.

### 발주 품목 드롭다운 (DECISIONS #72, #64 대체)
품목을 누르면 아래로 펼쳐진다(0.26s). 위에 발주량 칸(숫자 · 포장 × 개수 · −/+)과 최근 단가 꺾은선(기존 거래처 실선 · 식봄 점선과 범례, 펼칠 때 한 번 그린다). 날짜가 없는 이력은 마지막 칸을 이번 주로 두고 상대 주차(8칸이면 7주 전 ~ 이번 주)를 쓴다. 주차마다 마우스 · 터치 · 키보드(Tab · 좌우 화살표)로 원/기준 단위 가격을 확인하고, 없는 식봄 값은 수집 없음으로 표시한다. 포장 상품명과 응답의 포장당 수량 · 포장 이름을 함께 보이며 주문처 표는 포장 가격과 기준 단가를 구분한다. 아래 주문처 표: 기존 거래처 먼저, 나머지는 최저가순. 줄마다 이름 · "기존 거래처" · "최저가" 딱지, 포장 단가 `원/1망`, 그 수량의 총액, 도착, 담기 버튼(담은 줄은 `red-tint` 바탕 + "취소"). 추천 주문처(오늘 가장 싼 곳) 이름 위에 빨간 왕관 "추천". 가격이 없는 곳은 줄을 만들지 않는다.

### 거래 내역 (발주 이력)
은행 거래 내역 모양. 날짜 머리(15px `ink-3`) 아래 행: 왼쪽 품목(17px) · 거래처 · 수량, 오른쪽 금액(Lexend) · 상태. 입고 예정은 빨강, 거절은 행 전체를 흐리게. 카드 머리에 `‹ 연월 ›`, 연월을 누르면 연도 + 12개월 선택판.

### 영수증 (DECISIONS #66)
발주 이력 탭 맨 아래 카드. 제목 "이전 발주 거래 명세서", 같은 높이 오른쪽 위에 카메라 아이콘 + "올리기"(작은 버튼, 드롭존 없음). 장마다 한 줄: "거래처 이름 (M월 D일)"(날짜는 영수증 날짜, 못 읽었으면 올린 날), 오른쪽은 확정까지 끝났으면 "반영 완료" 하나, 읽는 중 · 실패(다시 읽기 · 지우기). 줄을 누르면 아래로 펼쳐 그 영수증 품목(이름 · 수량 · 금액). 올리면 가운데 모달: 읽는 동안 스피너(영수증 위 빨간 돋보기가 사람이 읽는 순서로 왼→오, 한 줄 내려 왼→오), 다 읽으면 같은 모달에서 상품명마다 재료 선택(맨 끝 "주기형 품목" · "무시") 뒤 확정 → 모달이 닫히고 반영. 확정 전이 남아 있으면 카드 위에 "확정 전 N" + 확인(모달을 다시 연다). 온보딩 마지막 단계도 같은 카드를 쓴다.

시연 계정은 서버의 기존 `GET /stores/me/demo-preparation`이 `eligible=true`일 때만 돋보기 로딩을 5초 보여준 뒤 항상 “분석 완료” 미리보기를 표시한다(#116). 가게 재료 이름과 선택 파일명으로 구성하고 확정은 화면 안에서만 끝낸다. 서버 문서·실제 재고·매출은 바꾸지 않으며 일반 계정의 실패는 성공으로 바꾸지 않는다.

시연 계정의 올리기는 앱 내부 전체 화면 파일 선택기를 연다(#117). Galaxy Tab 삼성 내 파일(One UI)의 태블릿 배치를 참고해 왼쪽 최근 파일/카테고리/내장 저장공간 메뉴, 오른쪽 PDF 파일 목록과 선택 가능한 A4 미리보기, 원형 선택 표시, 선택 개수와 하단 취소·완료 버튼을 둔다. 모의 OS 내비게이션 바는 표시하지 않는다. 작은 화면에서는 위치 메뉴를 서랍으로 연다. 검색·목록/그리드 전환·키보드 선택·Escape 취소를 지원한다.
현재 가게의 거래처/등록 상품 API를 읽어 거래처별 명세서를 한 장씩 준비하고, 파일 이름과 인식 결과의 거래처를 같은 데이터로 연결한다. 명세서는 시연용 가상 PDF 항목이며 실제 파일 전송이나 DB 쓰기는 하지 않는다. 0개 선택은 완료가 비활성화되고 취소하면 인식을 시작하지 않는다.

### 레시피 탭

## 온보딩 조회와 선택 확인 저장 (#113)

공용 헤더의 이름은 제공된 빨간 손글씨 `wordmark.png`로 표시한다. 상자 아이콘 `logo.png`는 기존 색·선을 보존하고 투명 상단/오른쪽 여백만 제거한다. 두 이미지는 원래 비율을 유지하며 링크의 접근 가능한 이름은 `지그재고 홈`으로 유지한다. 데스크톱·태블릿 재료 그림은 냉장고의 본체가 아닌 다리 끝과 창고의 바닥선이 같은 높이로 보이도록 맞춘다.

- 메뉴/질문 조회 전에는 카드·질문 제목·선택 버튼 자리의 공용 Skeleton을 표시한다. 정상 0건과 오류/다시 불러오기는 로딩과 구분한다.
- 마지막 답변 또는 건너뛰기는 마감 시각 화면으로 즉시 이동한다. 기본 메뉴·재료 저장은 가게별 session queue에서 계속한다.
- 저장 중에는 안내, 실패하면 답변 보관 안내와 ‘저장 다시 시도’를 다음 화면에 표시한다. 응답 전에 완료 토스트나 홈 데이터 완료를 표시하지 않는다.
- 새로고침은 보관된 작업을 같은 가게에서 복구하며 다른 로그인 세션으로 예전 요청을 재전송하지 않는다. 키보드·터치 입력과 reduced-motion은 기존 공용 부품을 따른다.

### 다중 주문처 가격 비교·주간 추이 (S15P31A308-349 · 350)

실제 응답에 있는 후보를 모두 표시하며, 상품 포장 가격/규격과 기준 단가를 별도 줄로 둔다. 비교 합계와 홈 절감액은 `기준 수량 환산 · 배송비 제외`다. 합성 가격은 `시연 합성 가격`으로 표시하며 상품 참조 링크는 실제 가격을 보장하지 않는다. 당일이 아닌 값·배송 미확인은 추천과 담기에서 제외한다. 홈·발주는 같은 화면 초안의 수량과 주문처를 쓴다.

그래프는 x 날짜/y 가격의 선·눈금·단위를 표시하고 서버 7일 집계 구간에 맞춘다. 범례에서 판매처를 선택하고 점 hover/탭/focus/좌우 방향키로 탐색한다. 툴팁은 날짜 주차와 실제 가격 두 줄, 별도 줄에 판매처와 집계 시작/끝일을 둔다. CSS 원형 점과 44px 터치 영역으로 비율 변형을 막고 수집 누락은 선을 끊는다.
